About Me

Software Development Engineer in Test

with 2+ years of combined experience in manual and automation testing. I design and build test solutions for web, mobile, API, AI-powered, and enterprise applications, with a focus on catching issues early and keeping releases reliable.


On the automation side, I work with Playwright (JavaScript) for web testing, Postman for API testing, and Maestro for mobile automation on Android and iOS. I integrate these into CI/CD pipelines (GitHub Actions, Jenkins), and I'm comfortable with Docker and Cloudflare R2. Day to day, my testing spans functional, regression, API, mobile, database, and security testing , with an eye toward end-to-end reliability.


I also test AI and LLM-based applications, covering prompt validation, AI response evaluation, RAG testing, and API-based LLM validation . To speed up my own test development, I use AI tools such as ChatGPT, Gemini, Claude, Codex, Cursor, Devin, Cline, Perplexity, Ollama, and the Groq API , along with Playwright MCP, to generate test scenarios, analyze results, and refine automation workflows.


My foundation includes STLC, test automation frameworks, the Page Object Model (POM), test case design, and defect management , all aimed at building test solutions that scale with the product. I like combining traditional QA discipline with newer AI-assisted approaches, since the two together tend to catch more than either one alone.
