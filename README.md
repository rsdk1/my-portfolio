# RajaSuma D.K — SDET Portfolio

A responsive portfolio inspired by the dark-blue/cyan/pink portfolio layout shown in the reference screenshots.

## Run locally

This version is plain HTML/CSS/JavaScript, so no npm installation is required.

### Option 1
Open `index.html` directly in a browser.

### Option 2 — local server
From this folder:

```bash
python3 -m http.server 5500
```

Then open:

http://localhost:5500

## Included

- Dark blue + cyan portfolio design
- Responsive navigation
- Animated role typing effect
- Hero, About, Skills, Services, Projects, Experience, Certifications and Contact sections
- LinkedIn and GitHub links
- Download CV button
- AI / LLM / RAG / Security testing sections
- Mobile responsive layout

## Important

The reference screenshot contains a person's portrait. This implementation intentionally uses an `RS` monogram instead of copying that person's image. Replace the monogram with your own professional photo if you want one.

The AI/LLM, RAG and security sections are positioned as skills/focus areas. Do not claim hands-on experience or certifications you have not actually completed.
